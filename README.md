# IDX Financial Data Scraper

A Python pipeline for scraping and structuring quarterly financial reports of companies listed on the **Indonesia Stock Exchange (IDX)** into clean, analysis-ready CSV files.

The pipeline runs in three sequential stages:

1. **Master data sync** — pulls sector, industry, and outstanding share data for each ticker via `yfinance` and writes them to `emitens.csv`.
2. **Report scraping** — downloads the raw financial report archive for each ticker/year/quarter from IDX.
3. **Report parsing** — extracts key financial metrics from the downloaded reports according to a configurable taxonomy mapping, producing `financial_reports.csv`.

## Project structure

```
conten/
├── data/
│   ├── watchlist.csv          # tickers to process
│   ├── taxonomy.csv           # common term -> source tag mapping, per taxonomy_type
│   ├── emitens.csv            # generated by the master data stage
│   ├── financial_reports.csv  # generated by the parsing stage
│   └── XBRL/{year}/{Q1,Q2,Q3}/{TICKER}_{year}_{period}.xbrl
├── model/
│   ├── master-data.py
│   ├── fetch_idx.py
│   └── arelle_loader.py
├── requirements.txt
└── run.py
```

## Usage

Run the full pipeline from the directory:

```bash
python run.py
```

This executes all three stages in order: master data sync → report scraping → report parsing.

## Skipping stages

| Flag | Effect |
|---|---|
| `--skip-master` | Skip the master data sync stage |
| `--skip-fetch` | Skip the report scraping stage |
| `--skip-parse` | Skip the report parsing stage |

Flags can be combined freely:

```bash
# Scrape and parse only, without syncing master data
python run.py --skip-master

# Re-parse already-downloaded reports only
python run.py --skip-master --skip-fetch

# Scrape only, without syncing master data or parsing
python run.py --skip-master --skip-parse
```

> **Note:** if `--skip-master` is used without `--skip-parse`, `run.py` checks that `data/emitens.csv` already exists before proceeding, and will raise an error asking you to run the master data stage first if it doesn't.

## Limiting the year range

Applies to the report scraping and parsing stages (the master data stage is unaffected, but accepts its own `--shares-start-year` when run directly):

```bash
python run.py --start-year 2023 --end-year 2026
```

Defaults: `--start-year 2023`, `--end-year <current year>`.

## Overriding data location

```bash
# Custom data directory (default: <run.py directory>/data)
python run.py --data-dir "D:\path\to\data"

# Custom watchlist file (default: <data-dir>/watchlist.csv)
python run.py --watchlist "D:\path\to\custom_watchlist.csv"
```

## Combining flags

All options can be combined as needed:

```bash
python run.py --skip-master --start-year 2024 --end-year 2026 --data-dir "D:\idx-data"
```

## Required input files

- **`data/watchlist.csv`** — requires a `ticker` column. Optional columns `priority`, `added_at`, and `is_processed` are supported by `fetch_idx.py` to control processing order and skip tickers that have already been completed.
- **`data/taxonomy.csv`** — requires `taxonomy_type`, `common_term`, and `xbrl_tag` columns. Any additional columns (e.g. `id`) are ignored.

## Output

- **`data/emitens.csv`** — issuer list with taxonomy type and outstanding shares
- **`data/XBRL/...`** — raw downloaded reports per ticker/year/quarter
- **`data/financial_reports.csv`** — final output: financial metrics per ticker, year, and period
- **`data/failed_downloads.csv`** — log of tickers that failed to download after retries (if any)

## Known limitations

- Reports for tickers under the `insurance` taxonomy type currently have partial field coverage — some balance-sheet metrics may fall back to generic tags and require verification.
- If a currency conversion module is not present, USD-denominated figures fall back to a fixed default exchange rate rather than a live rate.

## Disclaimer

This project is intended for personal research and quantitative analysis purposes only. It scrapes publicly available data from the IDX website; usage should comply with IDX's applicable terms of use, and the scraped data should not be redistributed as an official or authoritative source.
